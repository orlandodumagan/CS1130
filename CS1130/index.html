About this website

This is the website for viewing HTML, JavaScript programming and CSS examples for students who are taking the Introduction to Computing class (CS 1130). Simple examples involving basic HTML, JavaScript functions, user interaction, mathematical calculations, simple styling and page layouts are shown.

Student Assignments

  • Assignment #1 - Conversion

    Converts Celsius to Fahrenheit, Fahrenheit to Celsius, meters to feet and feet to meters.

  • Assignment #2 - Income Tax Calculator

    Computes the income tax for a given annual taxable income.

  • Assignment #3 - Loops

    Computes the factorial (while loop), sum (do-while loop) and average (for loop) of the first N natural numbers.

  • Assignment #4 - Simple Payroll

    Computes the gross pay, deductions and net pay of an employee.
